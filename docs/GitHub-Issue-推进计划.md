# GitHub Issue 推进计划

## 目标

基于当前开发计划，将尚未实现的能力拆分为明确的 GitHub Issue，并按 P0、P1、P2 分阶段推进。

## 当前 Issue 映射

### P0

- `#4` P0 文档页白屏与稳定性修复
- `#5` P0 设置页组件拆分与状态整理
- `#6` P0 建立前端状态管理与平台接口层
- `#7` P0 拆分前端 API 服务与统一错误处理

### P1

- `#8` P1 安卓首批原生桥接能力接入
- `#9` P1 Android 工程打包与首个 APK 输出

### P2

- `#12` P2 Android 安全区与软键盘体验优化

## 推进顺序

### 第一阶段：先稳住现有前端可用性

1. 优先处理 `#4`，修复文档页白屏与稳定性问题
2. 处理 `#5`，降低设置页复杂度
3. 处理 `#7`，收敛 API 层与错误处理
4. 处理 `#6`，建立后续安卓接入的状态与平台基础层

### 第二阶段：让安卓宿主可真正运行

1. 推进 `#8`，接入首批原生桥接能力
2. 推进 `#9`，生成首个可安装 APK
3. 在安卓环境下回归验证文档、设置、聊天等核心路径

### 第三阶段：补齐核心业务能力

1. 推进 `#11`，让对话页使用真实模型响应
2. 推进 `#10`，接入真实图谱数据与节点详情

### 第四阶段：做移动端体验优化

1. 推进 `#12`，处理安全区与软键盘问题
2. 推进 `#13`，建立离线缓存与本地配置持久化
3. 推进 `#14`，做图谱性能验证与高级交互优化
4. 推进 `#15`，补齐对话历史与会话管理
5. 推进 `#16`，设计并接入通知与任务提醒

## 明确暂不纳入当前阶段的内容

- 用户登录
- iOS 端适配
- 桌面端适配
- 大规模图谱性能专项重构
