### 1. P0：补齐 Android 原生文件真实上传链路

**状态：已解决**

**目标**
- 从原生 URI 读取真实文件内容
- 消除空 `File` 对象上传问题
- 完成 Android 文档上传端到端闭环

**验收标准**
- Android 端选择文件后可以成功上传到 `/api/v1/documents/upload`
- 上传文件不是空文件
- 对 50MB 以内支持格式能正确校验并给出错误提示

### 2. P0：实现聊天 API 并接入 ChatPage

**状态：已解决**

**目标**

- ChatPage 接入真实接口
- 支持最基本的对话上下文管理

**验收标准**
- 前端可以发起对话请求并显示模型响应
- 至少支持单轮/多轮基础上下文
- 失败时有明确错误反馈

### 3. P0：实现图谱查询 API 并接入 GraphPage

**状态：已解决**

**验收标准**
