## 文档信息
- **文档版本**：v1.0
- **创建日期**：2026-03-08
- **产品名称**：Kmap 知识图谱管理系统
- **文档状态**：初稿

---

## 1. 需求概述

### 1.1 产品定位
Kmap 是一款基于AI的知识图谱构建与管理平台，帮助用户将各类文档资料自动转化为结构化知识图谱，实现知识的可视化管理、智能查询和关联分析，提升知识利用效率。

### 1.2 产品目标
- 降低知识图谱构建门槛，无需专业技术背景即可快速生成知识图谱
- 实现多类型文档的自动解析与知识提取
- 提供直观的知识图谱可视化交互界面
- 支持基于知识图谱的智能问答功能
- 为用户提供知识资产管理的一站式解决方案

### 1.3 核心价值
- **高效性**：自动化处理文档，大幅降低知识图谱构建成本
- **智能化**：AI驱动的知识提取和关联分析
- **可视化**：直观的图谱展示，便于理解知识关联
- **可扩展性**：支持自定义服务商配置，适配不同AI模型

## 2. 核心功能详细描述

### 2.1 自定义服务商配置
#### 功能描述
支持用户配置不同的AI服务提供商，满足多样化的模型使用需求。

#### 功能详情
- **服务商管理**
  - 支持添加/删除/编辑AI服务商信息
  - 内置主流服务商预设（OpenAI、Anthropic、百度文心、阿里通义、腾讯混元等）
  - 支持自定义私有模型服务商配置
- **参数配置**
  - API密钥配置与安全存储
  - 模型选择与参数调整（温度、最大token数等）
  - 调用频率限制设置
  - 代理配置支持
- **测试功能**
  - 服务商连通性测试
  - 模型调用效果测试
  - 费用预估功能

### 2.2 文档上传处理
#### 功能描述
支持多种格式文档的上传、解析和预处理，为知识提取提供数据源。

#### 功能详情
- **文件上传**
  - 支持拖拽上传和点击上传两种方式
  - 支持批量上传多个文件
  - 支持的文件格式：PDF、Word(.docx/.doc)、PPT(.pptx/.ppt)、Excel(.xlsx/.xls)、TXT、Markdown、CSV、JSON
  - 单文件大小限制：默认100MB，可配置
- **文件管理**
  - 文件列表展示（文件名、大小、上传时间、处理状态）
  - 文件重命名、删除、下载功能
  - 文件分类标签管理
  - 上传进度实时显示
- **文档解析**
  - 自动文本提取与格式清洗
  - 表格内容识别与结构化
  - 图片OCR识别（可选配置）
  - 多语言文档自动检测
- **预处理功能**
  - 文本分段与语义切块
  - 重复内容去重
  - 噪声数据过滤
  - 格式标准化处理

### 2.3 AI对话功能
#### 功能描述
基于已上传的文档知识，提供智能问答交互。

#### 功能详情
- **对话交互**
  - 多轮对话上下文保持
  - 问题类型自动识别（事实查询、关系查询、分析查询等）
  - 流式响应输出
  - 对话历史记录保存与管理
- **回答增强**
  - 答案来源标注（引用具体文档片段）
  - 相关知识点推荐
  - 答案可信度评分
  - 支持追问和进一步解释
- **对话管理**
  - 对话会话创建、重命名、删除
  - 对话内容导出（Markdown、PDF格式）
  - 常用问题收藏功能
  - 对话搜索功能

### 2.4 知识图谱生成与交互
#### 功能描述
自动从文档中提取实体和关系，构建知识图谱，并提供可视化交互能力。

#### 功能详情
- **图谱构建**
  - 实体自动识别（人物、地点、事件、概念、组织等）
  - 关系自动提取与语义关联
  - 属性自动抽取与规范化
  - 实体消歧与合并
  - 图谱构建进度实时展示
- **可视化展示**
  - 力导向图布局展示
  - 节点和关系的样式自定义（颜色、大小、形状）
  - 多层级图谱展示与下钻
  - 图谱缩放、平移、旋转操作
  - 实体搜索与定位高亮
- **图谱交互**
  - 点击节点查看详情（属性、关联关系、来源文档）
  - 点击关系查看关联详情
  - 路径查询（两个节点之间的关联路径）
  - 子图谱筛选与导出
  - 图谱编辑功能（手动添加/删除/修改实体和关系）
- **图谱导出**
  - 导出为图片（PNG、SVG）
  - 导出为结构化数据（JSON、CSV、RDF）
  - 导出为第三方图谱平台兼容格式

### 2.5 首页仪表盘
#### 功能描述
为用户提供系统使用概览和核心数据统计。

#### 功能详情
- **数据统计**
  - 已上传文档数量统计
  - 已处理文档占比
  - 知识图谱实体总数
  - 知识图谱关系总数
  - 对话交互次数统计
- **最近活动**
  - 最近上传的文档列表
  - 最近构建的知识图谱列表
  - 最近对话记录
  - 系统通知与任务进度
- **快捷操作**
  - 快速上传文档入口
  - 快速创建图谱入口
  - 快速发起对话入口
  - 常用功能快捷访问
- **使用分析**
  - 文档类型分布统计
  - 图谱构建趋势图
  - 功能使用频率统计
  - 存储空间使用情况

### 2.6 状态提示系统
#### 功能描述
实时反馈系统运行状态和任务进度，提升用户体验。

#### 功能详情
- **任务进度提示**
  - 文档上传进度条
  - 文档解析进度提示
  - 图谱构建进度展示
  - 后台任务队列状态
- **操作反馈**
  - 操作成功/失败提示
  - 警告信息提示
  - 错误信息详情展示
  - 异步操作结果通知
- **系统状态**
  - AI服务连通性状态
  - 系统资源使用状态
  - 存储空间剩余提示
  - API调用额度提示
- **通知中心**
  - 任务完成通知
  - 系统公告
  - 异常告警通知
  - 通知已读/未读管理

## 3. 功能优先级划分

### 3.1 P0（最高优先级，必须实现）
1. 文档上传处理（基础格式支持、文本提取）
2. 自定义服务商配置（主流服务商支持、API密钥管理）
3. 知识图谱生成（基础实体关系提取、简单可视化）
4. AI对话功能（基础问答、上下文保持）
5. 状态提示系统（任务进度、操作反馈）

### 3.2 P1（次高优先级，重要功能）
1. 首页仪表盘（核心数据统计、快捷操作）
2. 知识图谱高级交互（路径查询、子图谱筛选）
3. 对话历史管理与导出
4. 图谱编辑功能
5. 表格和图片内容识别

### 3.3 P2（中优先级，体验优化）
1. 高级图谱样式自定义
2. 多语言支持
3. 文档分类标签管理
4. 对话收藏和搜索功能
5. 图谱多种格式导出

### 3.4 P3（低优先级，未来迭代）
1. 团队协作功能
2. 知识图谱版本管理
3. 图谱相似度分析
4. 自定义实体和关系类型
5. 第三方系统集成API

## 4. 非功能需求

### 4.1 性能需求
- 页面首屏加载时间 ≤ 2秒
- 文档上传响应时间 ≤ 1秒
- 单页文档（100页以内）解析时间 ≤ 30秒
- 知识图谱构建：10万字文档处理时间 ≤ 2分钟
- AI对话响应首包时间 ≤ 2秒
- 图谱页面渲染：1000节点以内流畅交互 ≤ 500ms
- 系统支持至少100并发用户同时操作

### 4.2 安全需求
- 用户API密钥加密存储，不可明文展示
- 文档数据用户私有隔离，不可跨用户访问
- 支持HTTPS传输加密
- 提供操作日志审计功能
- 敏感数据脱敏处理
- 支持用户数据导出和删除功能
- 防范常见Web安全漏洞（XSS、CSRF、SQL注入等）

### 4.3 兼容性需求
- 浏览器支持：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- 响应式设计，支持PC端和平板设备使用
- 支持Windows、macOS、Linux操作系统
- 最低屏幕分辨率支持：1280×720

### 4.4 部署需求
- 支持Docker容器化部署
- 支持单机部署和集群部署
- 提供自动化部署脚本
- 支持私有化部署，数据完全本地化
- 系统备份与恢复功能
- 监控与日志系统集成

### 4.5 易用性需求
- 核心功能操作路径不超过3步
- 提供新手引导和操作提示
- 界面设计符合主流用户使用习惯
- 错误信息清晰易懂，提供解决方案建议
- 提供完整的用户使用文档

## 附录
### 术语说明
- **实体**：知识图谱中的节点，代表现实世界中的具体事物或抽象概念
- **关系**：知识图谱中的边，代表实体之间的关联
- **RDF**：资源描述框架，一种用于描述网络资源的标准模型
- **OCR**：光学字符识别，将图片中的文字转换为可编辑文本的技术
