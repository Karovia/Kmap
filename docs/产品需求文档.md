## 1. 需求概述

### 1.1 产品定位

Kmap 是一款基于 AI 的安卓本地知识图谱应用，帮助用户将各类文档资料自动转化为结构化知识图谱，实现知识的可视化管理、智能查询和关联分析，提升知识利用效率。

### 1.2 产品目标

- 降低知识图谱构建门槛，无需专业技术背景即可快速生成知识图谱
- 实现多类型文档的自动解析与知识提取
- 提供适合移动端的知识图谱可视化交互界面
- 支持基于知识图谱的智能问答功能
- 以 Android 本地应用的方式交付核心能力

### 1.3 核心价值

- **高效性**：自动化处理文档，降低知识图谱构建成本
- **智能化**：AI 驱动的知识提取和关联分析
- **可视化**：直观的图谱展示，便于理解知识关联
- **本地交付**：以 App 形态安装使用，贴合移动场景

## 2. 核心功能详细描述

### 2.1 自定义服务商配置

#### 功能描述

支持用户配置不同的 AI 服务提供商，满足多样化模型使用需求。

#### 功能详情

- 支持添加、删除、编辑服务商信息
- 支持 OpenAI、Gemini、Claude 和自定义服务商
- 支持 API Key 配置、模型配置、默认服务商设置
- 支持分别配置对话模型供应商与 Embedding 模型供应商
- 支持连通性测试

### 2.2 文档上传处理

#### 功能描述

支持多种格式文档的上传、解析和预处理，为知识提取提供数据源。

#### 功能详情

- 支持文件选择与上传
- 支持的文件格式：PDF、DOCX、CSV、TXT、Markdown
- 单文件大小限制：当前界面层限制为 50MB，后续可配置
- 支持上传进度、状态展示、错误反馈、删除文档
- 文档处理状态包括：`pending`、`splitting`、`embedding`、`indexed`、`error`

### 2.3 AI 对话功能

#### 功能描述

基于已上传的文档知识，提供智能问答交互。

#### 功能详情

- 支持多轮对话
- 支持流式响应（规划中）
- 支持答案来源标注（规划中）
- 支持历史记录管理（规划中）

### 2.4 知识图谱生成与交互

#### 功能描述

自动从文档中提取实体和关系，构建知识图谱，并提供可视化交互能力。

#### 功能详情

- 支持实体和关系抽取
- 支持图谱节点可视化展示
- 支持节点详情展示（规划中）
- 支持缩放、平移、搜索和筛选（规划中）

### 2.5 首页仪表盘

#### 功能描述

为用户提供系统使用概览和核心数据统计。

#### 功能详情

- 已上传文档数量统计
- 知识图谱实体与关系统计
- 最近活动展示
- 快捷操作入口

### 2.6 状态提示系统

#### 功能描述

实时反馈系统运行状态和任务进度，提升用户体验。

#### 功能详情

- 文档上传进度提示
- 文档处理状态提示
- 操作成功/失败反馈
- 后续支持通知与后台任务完成提醒

## 4. 非功能需求

### 4.1 性能需求

- 页面首屏加载时间 ≤ 2 秒
- 文档上传响应时间 ≤ 1 秒
- AI 对话首包时间 ≤ 2 秒
- 图谱页面在中等规模节点数下保持流畅交互
- Android 真机环境下页面切换稳定无明显卡顿

### 4.2 安全需求

- 用户 API Key 加密存储，不可明文展示
- 文档数据需具备隔离与权限控制能力
- 支持 HTTPS 传输加密
- 敏感数据脱敏处理
- 支持后续用户数据导出和删除能力

### 4.3 平台与兼容性需求

- 当前正式交付平台：Android
- 开发调试阶段允许浏览器运行界面层，但不作为正式交付
- 适配主流 Android 版本
- 支持移动端竖屏场景优先

### 4.4 部署需求

- 前端界面层可打包为静态资源
- 通过 Android 宿主容器完成 App 打包
- 后端服务支持独立部署
