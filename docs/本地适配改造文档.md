# Kmap 文档处理全链路本地适配改造方案

## 一、改造概述

本次改造基于ONNX Runtime Mobile实现纯本地文档处理能力，支持无网络环境下的全流程文档解析、向量化、图谱构建和问答检索。改造完全兼容现有业务接口，现有代码无需修改即可无缝切换到本地模式。

## 二、代码结构变化

### 新增核心模块

```
backend/app/core/
├── local_inference.py        # 本地推理层，封装Qwen2和bge模型的ONNX推理
├── local_graph.py            # 本地轻量化图数据库实现
├── local_document_parser.py  # 本地文档解析器，支持多格式解析
└── initialization.py         # 本地服务初始化模块
```

### 修改核心模块

1. **app/core/config.py** - 新增本地模式相关配置项
2. **app/core/llm.py** - 新增本地模型支持，实现模式切换逻辑
3. **app/services/document_processor.py** - 改造文档解析流程，支持本地解析
4. **app/main.py** - 新增本地服务初始化逻辑
5. **app/api/v1/system.py** - 新增系统管理接口，支持运行模式切换

## 三、核心功能实现

### 1. 本地推理层 (local_inference.py)

#### 功能特性
- 基于ONNX Runtime实现Qwen2-0.5B大模型推理
- 基于ONNX Runtime实现bge-small-zh-v1.5向量模型推理
- 完全兼容LangChain的LLM和Embedding接口协议
- 支持CPU/GPU加速切换
- 支持流式输出（后续扩展）

#### 核心接口
```python
# LLM接口（兼容LangChain）
local_inference.llm.generate(prompt: str, max_new_tokens: int = 200) -> str
local_inference.llm.agenerate(prompt: str, **kwargs) -> str
local_inference.llm.invoke(messages: List[Any], **kwargs) -> AIMessage
local_inference.llm.ainvoke(messages: List[Any], **kwargs) -> AIMessage

# Embedding接口（兼容LangChain）
local_inference.embedding.embed_documents(texts: List[str]) -> List[List[float]]
local_inference.embedding.embed_query(text: str) -> List[float]
```

### 2. 本地文档解析 (local_document_parser.py)

#### 支持格式
- **文本类**: TXT、Markdown、JSON
- **文档类**: PDF（PyPDF2）、Word（python-docx）
- **表格类**: Excel（openpyxl+pandas）、CSV

#### 核心接口
```python
local_parser.parse(file_path: str) -> List[Dict[str, Any]]
local_parser.get_supported_formats() -> List[str]
```

### 3. 本地图数据库 (local_graph.py)

#### 实现方案
- 轻量化实现：基于JSON文件存储，无需外部依赖
- 兼容Neo4j核心接口，后续可无缝切换到Neo4j嵌入式版本
- 支持节点和关系的CRUD操作
- 支持基础Cypher查询

#### 核心接口
```python
# 节点操作
local_graph.db.create_node(label: str, properties: Dict) -> Node
local_graph.db.find_node_by_id(node_id: str) -> Optional[Node]
local_graph.db.find_nodes_by_label(label: str) -> List[Node]
local_graph.db.update_node_properties(node_id: str, properties: Dict) -> Node
local_graph.db.delete_node(node_id: str, delete_relationships: bool = True)

# 关系操作
local_graph.db.create_relationship(start_id: str, end_id: str, rel_type: str, properties: Dict) -> Relationship
local_graph.db.find_relationships(start_id: Optional[str], end_id: Optional[str], rel_type: Optional[str]) -> List[Relationship]
local_graph.db.update_relationship_properties(rel_id: str, properties: Dict) -> Relationship
local_graph.db.delete_relationship(rel_id: str)

# 查询
local_graph.db.query(cypher: str) -> List[Dict]
```

### 4. 模式切换机制

#### 三种运行模式
1. **纯本地模式 (local)**：所有功能都在本地执行，完全不需要网络
2. **纯云端模式 (cloud)**：所有功能都调用云端服务，与原有逻辑一致
3. **混合模式 (hybrid)**：优先使用本地能力，本地能力不足时自动回退到云端

#### 切换逻辑
- 通过配置文件`RUN_MODE`参数设置默认模式
- 支持通过API接口动态切换运行模式
- 模式切换对上层业务代码完全透明

## 四、配置说明

### 新增配置项 (config.py)
```python
# 本地推理配置
LOCAL_INFERENCE_ENABLED: bool = False  # 是否启用本地推理
LOCAL_LLM_MODEL_PATH: str = "./models/qwen2-0.5b-onnx/model.onnx"  # Qwen2模型路径
LOCAL_LLM_TOKENIZER_PATH: str = "./models/qwen2-0.5b-onnx"  # Qwen2分词器路径
LOCAL_EMBEDDING_MODEL_PATH: str = "./models/bge-small-zh-v1.5-onnx/model.onnx"  # bge模型路径
LOCAL_EMBEDDING_TOKENIZER_PATH: str = "./models/bge-small-zh-v1.5-onnx"  # bge分词器路径
LOCAL_USE_GPU: bool = False  # 是否使用GPU加速
LOCAL_EMBEDDING_DIM: int = 512  # 本地Embedding维度

# 运行模式: local(纯本地), cloud(纯云端), hybrid(混合模式，优先本地)
RUN_MODE: str = "cloud"

# 本地图数据库配置
LOCAL_GRAPH_DB_TYPE: str = "litegraph"  # litegraph 或 neo4j-embedded
LOCAL_GRAPH_DB_PATH: str = "./data/graphdb"  # 本地图数据库存储路径
```

### 环境变量示例 (.env)
```
# 本地模式配置

LOCAL_INFERENCE_ENABLED=true
LOCAL_LLM_MODEL_PATH=./models/qwen2-0.5b-onnx/model.onnx
LOCAL_LLM_TOKENIZER_PATH=./models/qwen2-0.5b-onnx
LOCAL_EMBEDDING_MODEL_PATH=./models/bge-small-zh-v1.5-onnx/model.onnx
LOCAL_EMBEDDING_TOKENIZER_PATH=./models/bge-small-zh-v1.5-onnx
LOCAL_USE_GPU=false
```

## 六、部署说明

### 1. 依赖安装
```bash
# 安装基础依赖
pip install onnxruntime transformers PyPDF2 python-docx openpyxl pandas

# GPU版本（可选）
pip install onnxruntime-gpu
```

### 2. 模型准备
1. 下载Qwen2-0.5B的ONNX版本模型到`./models/qwen2-0.5b-onnx/`目录
2. 下载bge-small-zh-v1.5的ONNX版本模型到`./models/bge-small-zh-v1.5-onnx/`目录
3. 确保模型文件路径与配置一致

### 3. 启动服务
```bash
# 纯本地模式启动
RUN_MODE=local LOCAL_INFERENCE_ENABLED=true python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# 混合模式启动
RUN_MODE=hybrid LOCAL_INFERENCE_ENABLED=true python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
