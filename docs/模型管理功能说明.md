# 模型管理功能说明

## 功能概述
模型管理模块允许用户下载、管理和使用本地开源LLM和Embedding模型，实现完全离线的AI能力。

## 主要功能

### 1. 模型市场
- 展示所有可下载的开源模型列表
- 支持按模型类型筛选（全部/对话模型/向量模型）
- 每个模型卡片显示：
  - 模型名称和类型标签
  - 模型描述
  - 参数大小、所需存储空间、量化精度
  - 相关标签
  - 下载按钮

### 2. 下载管理
- 支持断点续传
- 支持后台下载
- 实时显示下载进度和速度
- 支持暂停、恢复、取消操作
- 下载失败自动重试提示
- 最多支持2个并行下载

### 3. 本地模型管理
- 展示所有已下载的模型
- 支持切换默认模型
- 支持删除不需要的模型
- 显示模型下载时间和上次使用时间
- 默认模型无法删除

### 4. 存储管理
- 显示总存储空间、已用空间、可用空间
- 显示模型占用的总空间
- 支持一键清理未使用的模型
- 下载前自动检查存储空间是否足够

### 5. 权限处理
- 自动检查存储权限
- 权限不足时提示用户授权
- 支持跳转到系统设置手动开启权限
- 兼容Android 9+版本

## 技术实现

### 核心组件
- `ModelManager.tsx` - 模型管理主组件，整合所有功能
- `ModelCard.tsx` - 模型市场卡片组件
- `LocalModelCard.tsx` - 本地模型卡片组件
- `DownloadTaskItem.tsx` - 下载任务进度组件
- `StorageInfo.tsx` - 存储信息展示组件
- `PermissionPrompt.tsx` - 权限申请提示组件

### 状态管理
- 使用Zustand进行状态管理
- 自动轮询下载任务状态
- 无活跃下载时自动停止轮询，节省资源

### 接口封装
- `modelsApi` 封装了所有模型相关的后端接口
- 支持请求/响应数据的自动转换
- 统一的错误处理

### 权限处理
- 基于Capacitor权限系统
- 支持权限检查和申请
- 兼容Web和原生平台

## 使用说明

### 下载模型
1. 进入设置页面，找到「模型管理」模块
2. 在「模型市场」标签页浏览可用模型
3. 点击模型卡片上的「下载」按钮
4. 首次下载会申请存储权限，同意后开始下载
5. 可以在下载任务列表中查看进度和管理下载

### 切换默认模型
1. 进入「已下载」标签页
2. 找到想要设置为默认的模型
3. 点击「设为默认」按钮
4. 切换即时生效

### 删除模型
1. 在「已下载」标签页找到要删除的模型
2. 点击删除按钮，再次点击确认删除
3. 默认模型无法删除，需要先切换其他模型为默认

### 清理空间
1. 点击存储信息卡片上的「清理未使用」按钮
2. 系统会自动删除所有非默认且30天内未使用的模型
3. 清理完成后会显示释放的空间大小

## 后端接口列表
- `GET /api/v1/system/models` - 获取可下载模型列表
- `GET /api/v1/system/local-models` - 获取已下载模型列表和存储信息
- `POST /api/v1/system/models/download` - 触发模型下载
- `POST /api/v1/system/models/download/{taskId}/pause` - 暂停下载
- `POST /api/v1/system/models/download/{taskId}/resume` - 恢复下载
- `POST /api/v1/system/models/download/{taskId}/cancel` - 取消下载
- `GET /api/v1/system/models/download/{taskId}` - 获取单个下载任务状态
- `GET /api/v1/system/models/downloads` - 获取所有下载任务
- `POST /api/v1/system/models/switch` - 切换默认模型
- `DELETE /api/v1/system/models` - 删除本地模型
- `POST /api/v1/system/models/cleanup` - 清理未使用的模型
- `GET /api/v1/system/storage` - 获取存储信息

## 注意事项
- 模型文件较大，建议在WiFi环境下下载
- 下载过程中请勿关闭应用，否则可能导致下载失败
- 删除模型前请确认该模型不再需要，删除后无法恢复
- 存储空间不足时无法下载新模型，请及时清理
