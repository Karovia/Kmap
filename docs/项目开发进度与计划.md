# Kmap 项目开发进度与计划

## 项目概述

Kmap 是一款面向知识管理场景的 AI 安卓本地应用，提供文档上传、知识抽取、图谱浏览、智能问答和模型配置等能力。当前项目采用“前端界面层 + 后端服务 + 未来 Android 宿主”的推进方式。

## 技术栈

### 界面层

- React 19 + TypeScript
- Vite 6.x
- Tailwind CSS 4.x
- Lucide React + Motion
- D3.js（后续用于图谱增强）

### 安卓宿主（规划）

- Capacitor Android
- Capacitor Plugins + 自定义 Android Plugin

### 后端

- Python 3.11 + FastAPI + LangChain
- PostgreSQL 16+
- Qdrant
- Nebula Graph
- Redis 7+
- RabbitMQ 3.12+
