# Kmap 项目开发进度与计划

## 项目概述
Kmap 是一款基于 AI 的知识图谱管理与应用平台，支持文档上传、知识自动抽取、图谱可视化、智能问答等功能。

## 技术栈
### 前端
- React 19 + TypeScript
- Vite 6.x
- Tailwind CSS 4.x
- Lucide React + Framer Motion
- D3.js + 3D 图谱渲染

### 后端
- Python 3.11 + FastAPI + LangChain
- PostgreSQL 16+ (业务数据)
- Qdrant (向量数据库，本地部署)
- Nebula Graph v3.6+ (图数据库)
- Redis 7+ (缓存)
- RabbitMQ 3.12+ (消息队列)

### 3. 文档上传、分片、向量化处理模块 ✅
**完成时间**：2026-03-09

**交付成果**：
- 文档数据库模型（document、document_chunk表）
- 文档上传和管理API接口
- 异步任务处理队列（RabbitMQ）
- Unstructured.IO文档解析集成
- Qdrant向量存储集成

**API接口**：
- `POST /api/v1/documents/upload` - 文件上传
- `GET /api/v1/documents` - 获取文档列表
- `GET /api/v1/documents/{id}` - 获取文档详情
- `DELETE /api/v1/documents/{id}` - 删除文档
- `GET /api/v1/documents/{id}/status` - 获取处理状态

**文档处理流程**：
1. 文件上传 → 状态：pending
2. 异步解析分片 → 状态：splitting
3. 向量化处理 → 状态：embedding
4. 存储完成 → 状态：indexed
5. 错误 → 状态：error

**支持的文件格式**：
- PDF
- DOCX
- CSV
- TXT
- Markdown

**关键文件**：
- `backend/app/models/document.py` - 数据模型
- `backend/app/schemas/document.py` - Pydantic Schema
- `backend/app/api/v1/documents.py` - API路由
- `backend/app/worker/document_processor.py` - 异步消费者
- `backend/app/services/document_processor.py` - 核心处理逻辑

## 开发流程与验收机制

### 1. 任务分配
- 项目负责人按优先级分配任务
- 每个任务明确交付时间和验收标准

### 2. 开发流程
- 开发人员从dev分支创建feature分支
- 完成开发后提交PR

### 3. 代码审查
- 质量校验工程师审查所有PR
- 不通过则返回修改

### 4. 测试验证
- 代码审查通过后进行功能测试
- 不通过则返回修改

### 5. 用户验收
- 测试通过后合并到dev分支
- 通知用户进行测试验收

### 6. 代码推送
- 用户验收通过后
- 合并到main分支并推送到GitHub

### 7. 进度同步
- 每日同步开发进度
- 每周输出进度报告
